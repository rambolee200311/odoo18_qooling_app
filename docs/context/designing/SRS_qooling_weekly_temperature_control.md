## 0. 文档边界

本文档只承载 Weekly Temperature Control 的业务需求。Web、PDF、PDA、手写签名和 Odoo 多语言要求仅在其适用于温度记录时纳入。

## 1. 业务目标与范围

Weekly Temperature Control 用于记录客户集装箱内实际托盘温度，以及包装、未包装产品壳体、电解液和存储稳定性检查。

本期包含：

- Web、PDF 和 PDA 录入；
- 保存草稿、提交和仓库主管复核；
- 客户、集装箱、经理、日期和归档信息；
- 动态托盘及温度明细；
- 摄氏度温度值；
- 包装损坏、未包装产品壳体损坏、电解液泄漏和存储稳定性；
- 照片、备注、手写签名和归档信息。

当前实际记录频率为每天；“Weekly Temperature Control”名称、提醒周期和业务频率仍需统一。

## 2. 角色与入口

| 角色/入口 | 温度记录职责 |
|---|---|
| 库管 | 创建、填写和提交记录 |
| 仓库主管 | 复核记录 |
| Web | 录入、提交、手写签名和复核 |
| PDA | 录入、提交和手写签名 |
| PDF | 填写、提交并进入同一复核流程 |

Location 使用仓库档案；客户和集装箱号必填；经理从用户中选择。

## 3. 字段

### 3.1 基础和归档字段

| 字段 | 业务要求 |
|---|---|
| Date | 系统记录，用户可以修改 |
| Manager | 用户选择 |
| Customer | 必填 |
| Container Number | 必填 |
| Filled in by | 系统自动 |
| Filing date | 系统自动 |
| Number | 系统自动 |

### 3.2 托盘字段

- 用户动态记录实际托盘及温度；
- `Total Pallets` 记录实际托盘数量；
- 原模板展开至 `Pallet 65`，但 Odoo 不固定 65 个字段；
- 超过 65 个托盘时创建新记录；
- 温度单位为摄氏度；
- 单次测量、平均温度、多次测量和原始读数由人工复核决定，系统只记录结果。

### 3.3 检查字段

| 字段 | 业务要求 |
|---|---|
| 包装可见损坏 | 记录检查结果；选项以模板/用户填写为准 |
| 未包装产品壳体可见损坏 | 独立记录检查结果 |
| 电解液泄漏 | 记录检查结果 |
| 存储稳定性 | 记录托盘放置、堆叠等检查结果 |
| Attach photo | 非必填，不作为提交阻断条件 |
| Comments | 非必填 |
| Signature | 手写签名，必填 |

## 4. 功能需求

### 4.1 温度记录生命周期和入口

#### FR-FORM-01 创建表单记录

库管可以创建温度记录草稿。

#### FR-FORM-02 记录执行信息

系统记录用户和时间；用户可以修改日期/时间，并选择关联业务对象和 ID。

#### FR-FORM-03 保存草稿

草稿可反复修改；保存失败不得显示为成功。

#### FR-FORM-04 提交表单

完成必填字段和手写签名后才可提交；仓库主管负责复核。

#### FR-FORM-05 查询历史记录

授权用户可按表单类型、日期、执行人和业务参考查询温度记录。

#### FR-FORM-06 Web 入口录入和提交

Web 录入、草稿、提交和复核必须使用与 PDF/PDA 相同的温度字段和生命周期。

#### FR-FORM-07 PDF 入口录入和提交

PDF 字段、签名和归档信息登记到温度业务记录；缺少必填字段或签名不得标记为已提交，原 PDF 和失败原因须保留。

#### FR-FORM-08 Web/PDF 统一复核

Web、PDF 和 PDA 产生的温度记录进入同一复核流程，字段语义、权限和状态一致。

#### FR-FORM-09 多语言字段和选择值

字段名、帮助文本和选择值按当前 Odoo 用户语言显示单一翻译，不显示三语并列文本。

#### FR-FORM-15 PDA/Web 手写签名

PDA 和 Web 均须支持用户直接绘制手写签名；保存签名图像、签名人和签名时间。

### 4.2 温度专属需求

#### FR-FORM-30 创建温度记录

创建带有日期/时间、经理、客户和集装箱号的温度检查记录。当前业务记录频率为每天。

#### FR-FORM-31 记录温度检查上下文

记录经理、客户、集装箱号、执行人和适用地点；客户和集装箱号必填。

#### FR-FORM-32 记录每个托盘温度

动态记录每个实际托盘的温度和测量结果，并记录 Total Pallets。超过 65 个托盘时创建新记录。

#### FR-FORM-33 记录温度异常

记录包装损坏、未包装产品壳体损坏、电解液泄漏、存储稳定性和温度异常；系统保存人工填写结果。

#### FR-FORM-34 记录温度异常处置

记录人工复核决定的复测、隔离和其他处置结果。系统不自动判断 `40°C`、正常范围或复测等待时长。

#### FR-FORM-35 记录表单证据

记录照片、备注、手写签名、填写人、归档日期和表单编号。签名必填；照片和备注非必填，不作为提交阻断条件。

## 5. 业务规则

| 编号 | 温度记录规则 |
|---|---|
| BR-FORM-01 | 已提交记录必须保留执行人和执行时间 |
| BR-FORM-02 | 草稿可修改；已提交记录撤回到草稿后修改，不保留原始值和更正历史 |
| BR-FORM-05 | 损坏、泄漏、存储或温度异常结果不得被记录为全部正常 |
| BR-FORM-06 | 每个实际托盘的温度应独立记录 |
| BR-FORM-07 | 温度结果可按类型、日期和执行人追溯 |
| BR-FORM-09 | 电池温度超过 `40°C` 时，由人工复核决定是否记录隔离或其他异常处置 |
| BR-FORM-10 | 多个托盘温度异常时，复测和外部适应过程由人工复核决定并由系统记录结果 |
| BR-FORM-11 | 业务异常保留原始检查结果、说明和人工处置结果 |
| BR-FORM-13 | 包装损坏和未包装产品壳体损坏分别记录 |

温度范围、预警、隔离、复测和异常是否阻止提交均由人工复核决定，系统只记录用户结果。

## 6. 状态与配置

| 状态 | 温度记录含义 |
|---|---|
| 草稿 | 可填写、保存和修改 |
| 已提交 | 已完成提交，等待或完成主管复核 |
| 异常待处理 | 存在人工标记的异常 |
| 已关闭 | 人工确认异常处理完成 |

配置事实：

- 温度单位为摄氏度；
- 托盘明细动态记录；
- 超过 65 个托盘时创建新记录；
- 当前实际记录频率为每天。

| AC-14 | 无复核权限的用户不能执行复核 |

| AC-25 | 包装损坏和未包装产品壳体损坏独立保存 |
| AC-26 | 温度记录证据重新打开后仍可查看 |
| AC-27 | Web 温度记录可录入、提交和复核 |
| AC-28 | PDF 原件、字段、签名和提交结果可追溯 |
| AC-29 | PDF 缺少必填字段或签名时拒绝提交 |

| AC-31 | 用户只看到当前语言的字段名和选择值 |
| AC-33 | PDA/Web 可绘制并保存手写签名 |
| AC-34 | 未完成手写签名时拒绝完成或提交 |

## 8. 已确认的用户决策边界

温度控制名称和实际每日记录频率由用户决定；系统不自行统一名称、推导频率或自动改变记录要求。

图片上传非强制，不作为提交阻断条件。温度正常范围、预警、隔离、复测及异常是否阻止提交，均属于已确认的人工决策边界；系统只记录用户结果，不自动判断。
