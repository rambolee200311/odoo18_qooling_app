# Inbound PDA 触控 Web 技术债

> 技术债 ID：`TD-INBOUND-PDA-001`  
> 状态：Open  
> 记录日期：2026-09-22  
> 关联范围：Inbound Form  
> 关联模块：`wd_qooling_app`

## 1. 技术债描述

当前 Inbound Form 已实现 Odoo 标准 Web 表单，并通过响应式布局和 Owl
签名组件支持较小屏幕访问。但这不等同于专门的 PDA 触控 Web 界面。

当前实现缺少：

- PDA 专用页面布局和导航；
- 面向触控操作的大尺寸控件与分步填写体验；
- PDA 页面级的固定操作区和提交反馈；
- 面向 PDA 的真实设备/视口验收基线。

当前的移动视口验证只能证明标准 Odoo Web 页面可以在小屏幕上使用，不能宣称
专用 PDA Web 界面已经完成。

## 2. 目标

为 Inbound Form 增加专门的 PDA 触控 Web 界面，同时继续复用同一
`wd.qooling.inbound.form` ORM 记录和提交规则。

该界面不新增仓库业务流程，不自动判断检查结果，也不改变 Web 入口的字段语义。

## 3. 建议实现范围

1. 增加 PDA 专用入口和 Owl 页面组件；
2. 按 PDA 触控操作重新组织字段分步/分区；
3. 提供大尺寸触控控件、清晰的上一项/下一项/保存/提交操作；
4. 优化签名画布在 PDA 触控笔和手指输入下的尺寸与反馈；
5. 明确加载、保存、提交和错误提示；
6. 使用稳定的 `data-testid` 支持 PDA E2E 验证；
7. 在至少一个真实 PDA 或等效触控设备上完成 HVR。

## 4. 非目标

- 不实现离线缓存或断网同步，除非另行批准；
- 不实现条码扫描、库存移动或仓库业务联动；
- 不复制一套新的 Inbound ORM 模型；
- 不把移动视口浏览器测试继续当作专用 PDA 界面验收。

## 5. 验收条件

完成后至少应验证：

- PDA 入口可独立打开 Inbound Form；
- 主要字段无需精确鼠标操作即可完成填写；
- 签名、保存、提交和错误提示适合触控操作；
- PDA 记录与 Web 记录使用相同字段和状态；
- HVR 记录明确标记为专用 PDA 界面验证，而不是普通响应式 Web 验证。

## 6. 影响与优先级

| 项目 | 内容 |
|---|---|
| 优先级 | P1 |
| 当前影响 | PDA 可用性和需求符合性不足 |
| 数据影响 | 无；继续使用现有 ORM 模型 |
| 业务流程影响 | 无；不新增自动处置流程 |
| 关闭条件 | 专用 PDA 触控 Web 实现完成并通过 HVR |
