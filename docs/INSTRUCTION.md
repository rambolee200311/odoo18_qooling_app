# Qooling Forms 用户操作指南

## 1. 系统登录

1. 打开管理员提供的 Odoo 地址。
2. 输入用户名和密码登录。
3. 登录后进入 **Qooling** 菜单。
4. 根据工作需要选择：
   - 入库单列表；
   - 出库单列表；
   - 温度记录列表；
   - PDA 表单入口。

页面语言由 Odoo 用户语言设置决定。系统默认使用英语，也支持荷兰语和简体中文。

## 2. 单据状态

| 状态 | 说明 |
|---|---|
| 草稿（Draft） | 单据尚未提交，可以继续编辑 |
| 已提交（Submitted） | 单据已完成提交，只能查看，不能修改 |
| 异常待处理（Exception pending） | 单据存在异常，需要按照业务流程处理 |
| 已关闭（Closed） | 单据流程已经结束，只能查看 |

不同单据类型显示的状态可能不同。

## 3. Web 端操作

### 3.1 新建单据

1. 进入对应的 Inbound、Outbound 或 Temperature 菜单。
2. 点击新建或创建按钮。
3. 按页面顺序填写字段。
4. 点击 **保存** 保存草稿。
5. 完成全部检查和签名后点击 **提交**。

### 3.2 继续编辑草稿

1. 打开对应的历史列表。
2. 找到状态为 Draft 的记录。
3. 打开记录并继续填写。
4. 修改后保存或提交。

### 3.3 查看已提交记录

打开状态为 Submitted、Exception pending 或 Closed 的记录即可查看。
已提交记录为只读，不能修改字段、媒体或签名。

## 4. Inbound 入库单

### 4.1 基本信息

填写以下信息：

- 位置；
- 日期；
- 主管；
- 业务参考号；
- 集装箱编号 / 货运编号；
- 货物状态；
- 卸货许可。

### 4.2 检查

根据实际情况完成：

- 可见损坏检查；
- 收货数量检查；
- 产品质量检查；
- 包装状况；
- 气体测量。

### 4.3 ADR 与温度

1. 选择是否为 ADR 货物。
2. 如果选择 **是**，填写：
   - UN 编号；
   - 是否测量温度；
   - 是否登记托盘温度；
   - 每托盘平均温度。
3. 必填检查未完成时，系统不允许提交。

### 4.4 证据和签名

在证据区域上传相关照片或视频，在签名区域完成仓库签名。

## 5. Outbound 出库单

### 5.1 基本信息

填写以下信息：

- 位置；
- 到达时间；
- 主管；
- 参考号；
- 货物类型；
- MRN 编号；
- 封条编号；
- 开始装货时间；
- 结束装货时间。

### 5.2 装货和车辆检查

根据实际情况完成页面中的检查项，包括：

- 装货计划；
- ADR 分隔和兼容性；
- 重量分布；
- 装货损坏和数量；
- 货物包装、识别和固定；
- 车辆 ADR 证书、灭火器和 ADR 标志；
- 固定材料、TREM 卡和其他车辆检查；
- 司机安全背心、护目镜、防护手套；
- 车轮止动块、防水篷布、手电筒、铲子；
- 接液盘、洗眼器和警示三角牌。

### 5.3 ADR 和温度

根据货物情况填写 ADR、UN 编号、正式运输名称和测量温度。

### 5.4 司机和仓库签名

Outbound 可以分别填写：

- 司机签名；
- 仓库签名。

签名是否必填以当前业务流程和页面提示为准。

## 6. Temperature 温度记录

### 6.1 基本信息

填写以下信息：

- 日期；
- 经理；
- 客户；
- 集装箱编号；
- 位置。

### 6.2 托盘温度

1. 在快速录入框输入温度。
2. 按回车增加一条托盘温度记录。
3. 检查每个托盘的温度。
4. 如需清空，可以点击 **清除所有温度**。

每个托盘的温度会独立保存。

### 6.3 状况检查

完成以下检查：

- 包装可见损坏；
- 未包装外壳损坏；
- 电解液泄漏；
- 储存稳定性。

### 6.4 提交

完成温度、检查、证据和签名后提交。
缺少必填信息或签名时，系统会显示提示并阻止提交。

## 7. PDA 看板

### 7.1 查看历史记录

进入 PDA 后，系统先显示对应类型的历史看板。
Inbound、Outbound 和 Temperature 只显示各自类型的记录。

看板显示：

- 单据编号；
- 状态；
- 日期；
- 业务参考信息；
- 操作按钮。

### 7.2 打开记录

- Draft：点击 **编辑草稿**；
- Submitted：点击 **打开**，进入只读页面；
- Exception pending / Closed：打开后查看记录详情。

### 7.3 新建记录

点击 **新建记录** 创建新的 PDA 单据。
新记录在保存前显示 `New`，首次保存后系统会生成正式单据编号。

## 8. PDA 看板筛选

筛选区默认收起，点击箭头可以展开或收起。

可使用以下条件：

- **From**：开始日期，可以留空；
- **To**：结束日期，可以留空；
- **Document number**：支持模糊搜索，不区分大小写；
- **Status**：从下拉列表选择状态。

操作方式：

1. 输入筛选条件。
2. 点击 **Filter**。
3. 查看筛选结果。
4. 点击 **Clear** 清空条件。

`From` 和 `To` 包含当天日期。如果开始日期晚于结束日期，系统会显示错误提示。
筛选后返回看板不会自动恢复之前的筛选值。

## 9. 照片、视频和附件

- 单张图片最大 `10 MB`；
- 单个视频最大 `100 MB`；
- 每条记录最多 `20` 个媒体文件；
- 可以拍照、录制视频或从设备选择文件；
- 预览媒体时，视频可以使用播放控制；
- 保存后媒体与当前单据关联；
- 提交后媒体不能删除或修改。

如果上传失败，请检查文件类型、文件大小和当前单据状态。

## 10. 手写签名

1. 进入签名步骤。
2. 使用鼠标、触控笔或手指在签名区域书写。
3. 如需重写，点击 **清除签名**。
4. 确认签名无误后保存或提交。

提交后签名只读。

## 11. 多语言切换

语言由 Odoo 用户偏好设置控制：

| 语言 | 代码 |
|---|---|
| English | 默认 |
| Nederlands | `nl_NL` |
| 简体中文 | `zh_CN` |

切换语言后重新打开 Web 或 PDA 页面，字段名、选择值、按钮、状态和提示会使用对应语言。

## 12. 常见问题

### 为什么不能提交？

请检查：

- 必填字段是否填写；
- ADR 相关字段是否完整；
- Temperature 是否已完成必需的温度记录；
- 是否已经完成必要签名；
- 当前记录是否已经提交。

### 为什么不能修改记录？

Submitted、Exception pending 或 Closed 记录可能是只读状态。
请返回看板，编辑 Draft 记录或创建新记录。

### 为什么看不到历史记录？

请确认：

- 当前进入的是正确的单据类型；
- 筛选条件没有排除目标记录；
- 用户具有对应的 Odoo 访问权限；
- 已点击 **Clear** 清除筛选条件。

### 为什么媒体不能上传？

请确认文件是图片或视频，并检查文件大小是否超过限制。
已提交记录不能继续上传媒体。
